    How to use the ROSA HCP Cost Calculator

    Build an HCP worker-node cost estimate in three steps. Hover any ? or action button for field-level tips. Amounts are planning estimates in USD, not a formal quote.

    Recommended workflow: Size your clusters in Step 1, optionally add discounts in Step 2, then open Step 3 to review results. Use Share to send a colleague the same scenario, or Open in Fleet Optimizer for fleet-level comparisons.

    Step 1 - Cluster sizing

    Add one or more instance types and node counts. Each row is a single-AZ worker pool for a region.

    • Basic mode: Flat instance rows plus a cluster count. The HCP cluster fee scales with that count.
    • Expert mode: Named clusters, each with machine pools (instance type, AZ, count). The HCP cluster fee is one fee per cluster. Basic and Expert keep separate sizing data.
    • Remembered locally: This browser stores your last mode, Basic rows, Expert clusters, and Step 2 discounts. Use Reset saved data to clear that and restore defaults. Share links still override on open.
    • Region and filters (Basic): Choose region, architecture, category, and family to narrow the instance list, then Add a type.
    • Count: Exact worker node count for that pool. Changes apply automatically.
    Use at least one cluster per selected region. Mixed regions are supported as separate rows.

    Step 2 - Discounting (optional)

    • Approx EC2 Savings Plan discount: Planning discount applied only to EC2 cost, not ROSA fees.
    • Private Offer - Red Hat: PAYGO, 1-year (33% off), or 3-year (55% off) for the Worker Node Fee Per 4 vCPU.
    • Additional programs: Reference list of AWS and Red Hat incentives. These do not change the math.

    Step 3 - Results

    The first time you expand Results, accept the non-binding estimate disclaimer (remembered in a cookie).

    • Summary table: Per-pool EC2, Node Fee, and totals, plus HCP cluster fee.
    • Private Offer comparison: PAYGO / 1-year / 3-year scenario totals with the selected tier highlighted and cost differences for the others.
    • Summary price unit: Switch hourly, monthly (730 hours), or yearly.
    • Export / Import CSV: Save or reload sizing, discounts, and a summary snapshot.
    • Share: Copy a link or code so someone else can reload the same scenario.
    • Open in Fleet Optimizer: Projects this scenario into fleet-level vCPU totals for broader optimization modeling.
    This calculator excludes EBS, load balancers, data transfer, NAT gateways, and other non-worker EC2 charges. Fleet Optimizer adds estimated EBS (~$24/node/mo), so totals there are usually higher.

    What the fees mean

    • EC2 cost: On-demand worker node pricing from the snapshot, after any EC2 discount.
    • Node Fee: ROSA Worker Node Fee Per 4 vCPU (PAYGO $1,500/year per block, with Private Offer discounts).
    • HCP cluster fee: $0.25/hour ($182.50/month) per cluster.
